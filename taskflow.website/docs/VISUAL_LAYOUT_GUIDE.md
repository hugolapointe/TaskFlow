## Hiérarchie des conteneurs

### Niveau 1: Body
- **Width:** 100%
- **Background:** Transparent
- **Role:** Canvas global

### Niveau 2: .app
- **Width:** 100%
- **Min-height:** 100vh
- **Background:** `var(--bg-app)` (dark blue)
- **Role:** Wrapper principal avec background

### Niveau 3: .header et .main-content
- **Max-width:** 1200px
- **Margin:** 0 auto (centrage)
- **Padding:** Responsive (xl/lg/md/sm)
- **Background:** Transparent (laisse voir --bg-app)
- **Role:** Zones de contenu centrées

### Niveau 4: Composants (.container)
- **Width:** 100% (de leur parent)
- **Background:** `var(--bg-surface)` (lighter dark)
- **Border:** 1px solid
- **Border-radius:** var(--radius-xl)
- **Role:** Cards de contenu

## Variables CSS utilisées

```css
/* Spacing */
--spacing-sm: 0.5rem;    /* 8px  - Mobile */
--spacing-md: 0.75rem;   /* 12px - Tablet */
--spacing-lg: 1rem; /* 16px - Desktop */
--spacing-xl: 1.5rem;    /* 24px - Extra spacing */
--spacing-2xl: 2rem;  /* 32px - Section spacing */

/* Colors */
--bg-app: hsl(220, 39%, 11%);        /* Dark blue background */
--bg-surface: hsl(220, 26%, 18%);    /* Lighter dark for cards */
--bg-elevated: hsl(220, 18%, 26%);   /* Even lighter for inputs */
--text-primary: hsl(0, 0%, 98%); /* Almost white text */

/* Borders */
--border-subtle: hsl(220, 18%, 26%);
--border-default: hsl(217, 12%, 34%);

/* Border Radius */
--radius-xl: 1rem;  /* 16px - Large rounded corners */
```

## Checklist visuelle

### ? Desktop (> 768px)
- [ ] Background `--bg-app` visible sur les côtés
- [ ] Contenu centré dans une colonne de 1200px max
- [ ] Marges de 16px entre le contenu et les bords du container
- [ ] Header et main-content parfaitement alignés verticalement

### ? Tablet (768px)
- [ ] Marges réduites à 12px
- [ ] Contenu toujours lisible
- [ ] Pas de scroll horizontal
- [ ] Background peut ne plus être visible (ou très peu)

### ? Mobile (? 480px)
- [ ] Marges minimales de 8px
- [ ] Contenu utilise presque toute la largeur
- [ ] Interface reste utilisable avec le pouce
- [ ] Aucun débordement horizontal

### ? Tous les écrans
- [ ] Smooth resize (pas de jump)
- [ ] Texte toujours lisible
- [ ] Boutons accessibles
- [ ] Cohérence visuelle maintenue
